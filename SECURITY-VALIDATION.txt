Deployment procedure (authorized by the subsequent release request)
1. Review and commit these changes, then deliver them to the deployment branch.
2. Build the intended deployment from that revision with a fresh base pull;
   restarting an existing image does not update Node or npm dependencies.
3. Redeploy only personal-bouncer, preserving DISCORD_TOKEN and the existing
   /app/data persistent volume. Do not delete or replace its database.
4. Verify node --version is v22.23.4 (or a newer patched maintained 22.x), inspect
   installed dependency versions, and check service logs/Discord readiness.
5. With explicit authorization, exercise owner setup, denied non-owner commands,
   failed/successful verification and role assignment in a suitable test guild.
